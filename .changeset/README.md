# Changesets

`skyportal-js-models`). They are versioned in lockstep (`fixed` in
`config.json`), so one changeset covers both.

The Python packages use towncrier fragments in [`changes.d/`](../changes.d)
instead; see [RELEASING.md](../RELEASING.md).
